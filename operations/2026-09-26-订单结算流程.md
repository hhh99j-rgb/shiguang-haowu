# 订单与结算流程

- 生效日期：2026-09-26
- 支付与履约：由商品对应的天猫官方旗舰店完成
- 本站职责：保存购物袋、生成跳转记录、记录用户确认的购买结果
- 本站不处理：淘宝登录、支付密码、银行卡、支付回调、物流和退款

## 用户流程

1. 用户将商品加入购物袋，点击“去结算”。
2. 本站按官方店拆分清单，展示参考金额和风险提示。
3. 用户点击官方店按钮时，本站先生成“待确认”记录，再打开官方店。
4. 用户在天猫选择实际规格、确认价格并完成支付。
5. 用户返回本站，选择“已在天猫下单”“稍后确认”或“未完成购买”，可选填天猫订单号。
6. “我的订单”展示本机记录，并提供官方店、淘宝订单中心和 JSON 导出入口。

## 数据边界

- 订单记录保存在浏览器 `localStorage` 的 `shiguang-orders-v1` 键中。
- 清理浏览器数据或更换设备不会自动同步，重要记录应定期导出。
- 天猫未向本站提供订单查询授权，因此本站状态以用户手动确认结果为准。
- 商品价格、规格、库存、运费、发货和售后状态均以天猫订单为准。
